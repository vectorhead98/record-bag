# Record Bag

## Private music catalog

### Built with

- [**typescript**](https://www.typescriptlang.org/) > end-to-end
- [**bun**](https://bun.com/) > js toolkit
- [**hono**](https://hono.dev/) > backend framework
- [**vite**](https://vite.dev/) > frontend build tool
- [**react**](https://react.dev/) > ui library
- [**tanstackForm**](https://tanstack.com/form/latest) > headless form library
- [**tanstackRouter**](https://tanstack.com/router/latest) > file based routing
- [**tanstackQuery**](https://tanstack.com/query/latest) > data fetching & state managment
- [**shadcn**](https://ui.shadcn.com/) > component library
- [**tailwind**](https://tailwindcss.com/) > css framework
- [**biome**](https://biomejs.dev/) > format & lint
- [**turboRepo**](https://turborepo.dev/) > workspace orchestration
- [**zod**](https://zod.dev/) > validation
